# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I learned how to work with Linux, manage users, check system information, organize files, and document my work using Markdown and GitHub.

## Objectives

- Access a Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed the Ubuntu 24.04 Linux Playground using KillerCoda.
2. Created a new Linux user with sudo privileges.
3. Logged in using the new user account.
4. Checked the username, working directory, and hostname.
5. Gathered basic system information.
6. Created folders and Markdown files.
7. Prepared the files for the Cloud Computing portfolio.

## Linux Commands Used

- `whoami` – Displays the current username.
- `pwd` – Displays the current working directory.
- `hostname` – Displays the hostname.
- `adduser` – Creates a new user.
- `usermod` – Modifies a user account.
- `su` – Switches to another user.
- `uname -r` – Displays the kernel version.
- `lscpu` – Displays CPU information.
- `free -h` – Displays memory information.
- `df -h` – Displays disk space.
- `mkdir` – Creates directories.
- `touch` – Creates files.
- `cat` – Displays file contents.
- `nano` – Edits text files.

## Skills Learned

I learned how to navigate a Linux environment, manage users, check system information, create and organize files, and prepare technical documentation using Markdown.
